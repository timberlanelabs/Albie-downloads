# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 11. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 11 source is identified by immutable tag `build-11` (commit `e05a75b`) in the private repository. Tap the initials/avatar on Home to edit name and handicap. Cancel discards the draft; Save preserves active-round and history data.

Update over build 9 or 10 without deleting the app. Older builds still have the previously documented history-format incompatibility; preserve their installation if you need its local test data.
