# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 17. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 17 adds native selectable shot maps for active and saved rounds with captured GPS, a Sunstone Mock GPS default, and first-club selection on each new hole. Satellite imagery requires network/cache coverage. Update builds 9–16 in place without deleting local data.
