# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 18. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 18 adds a Yards or Meters choice under Profile → Distances. Save your preference to update course setup, live and saved scorecards, and shot maps. Existing profiles default to yards; switching units preserves your recorded measurements and scores. Onboarding is unchanged. Update builds 9–17 in place without deleting local data.
