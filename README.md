Version 1.0, build 13. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 13 source is identified by immutable tag `build-13` (commit `f4c5abf`) in the private repository. Older rounds now show Incomplete; scorecard content has 24-point outer padding. Stored completion provenance and scores are unchanged.
