# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 15. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 15 keeps scorecard headers forest green in light/dark mode, distinct from mint totals. Install over builds 9–14 without deleting the app to retain profile, active round and saved history. Builds 8 and earlier lack the required history field; preserve any needed test data before reinstalling.
