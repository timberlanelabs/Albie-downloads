# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 12. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 12 source is identified by immutable tag `build-12` (commit `f979f2d`) in the private repository. It adds the traditional Albie scorecard, large-text hole summaries, incomplete/unknown completion labels and Home accessibility polish.

Update over build 9, 10 or 11 without deleting the app. Older builds retain the previously documented history-format incompatibility; preserve their installation if you need its local test data.
