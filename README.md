# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 10. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 10 source is identified by immutable tag `build-10` (commit `68463ff`) in the private repository. End round early now saves completed holes to history; unfinished/untouched holes are excluded. Discard round is a separate destructive action.

Update over build 9 without deleting the app; its stored data remains compatible. Builds 8 and earlier require the previously disclosed delete/reinstall, removing the local profile/test round.
