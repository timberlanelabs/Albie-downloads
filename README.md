# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 7. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 7 source is identified by immutable tag `build-7` (commit `5f22b07`) in the private repository. Home includes developer Mock GPS controls with a map and override toggle; real GPS/shot capture is not connected yet.
