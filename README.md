# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 16. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 16 retains unplayed layout metadata for newly archived incomplete rounds; score cells show dashes and completed-hole scoring stays unchanged. Existing archives remain readable but cannot recover missing layout. Update builds 9–15 in place without deleting Albie. Builds 8 and earlier lack the required history field; preserve needed test data before reinstalling.
