# Albie downloads

[Install Albie](https://timberlanelabs.com/Albie-downloads/) from Safari on a registered iPhone or iPad.

Version 1.0, build 4. Requires iOS/iPadOS 26.2 or later. Provisioning profile expires August 20, 2027.

Only installation assets are hosted here. Albie source code is maintained in a separate private repository. The IPA is public; installation is limited to devices included in its signed provisioning profile.

Build 4 source is identified by immutable tag `build-4` (commit `5c21319`) in the private repository. It adds a temporary End round control for testing and adjusts round-setup transitions. Ending discards the active round without history.
